# Hotel Mystique Magic

A multi-page hotel website built with HTML, CSS, JavaScript, and Bootstrap, with a Drift integration.

## Pages

- Home: introduction to the hotel
- Rooms: accommodation information
- Dining: food and dining presentation
- Spa: wellness information
- Services: hotel amenities
- Contact: contact page

## Run locally

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. No build step is required. Some styles, images, and integrations may depend on external services and an internet connection.

## Scope

This repository is a front-end website project. It does not include a verified booking, payment, or reservation-management backend.
