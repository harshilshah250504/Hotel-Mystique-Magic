## The experience

A front-end hotel website presenting accommodation, dining, wellness, amenities, and contact information across six pages.

## Explore the pages

- **Home** — hotel introduction and navigation.
- **Rooms** — accommodation presentation.
- **Dining** — dining information.
- **Spa** — wellness presentation.
- **Services** — amenities and services.
- **Contact** — contact-page experience.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. No build step is required. External styles, images, and integrations may require internet access.

## Scope

The repository demonstrates a multi-page front-end implementation with Bootstrap and a Drift integration. It does not include a verified booking, payment, or reservation-management backend. Third-party integrations depend on their external services.
